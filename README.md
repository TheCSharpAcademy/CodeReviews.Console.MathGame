# Math Game - The C# Academy
This project is part of [The C# Academy](https://thecsharpacademy.com).
This project is designed to introduce Object-Oriented Programming (OOP) in C# as well as building an application in C#.

## Description
MathGame is a console application for practicing mental math through quizzes. The user answers a series of math operations and gets feedback on their performance.

## Launch the project

### Prerequisites: Install .NET 10
- Go to the official [.NET website](https://dotnet.microsoft.com/download) and download the .NET 10 SDK.

### Clone the repo
- With URL
```bash
git clone https://github.com/Louis-dub/CodeReviews.Console.MathGame.git
```
- With SSH
```bash
git clone git@github.com:Louis-dub/CodeReviews.Console.MathGame.git
```

### Install dependencies
```bash
dotnet restore
```

### Launch the project
```bash
dotnet run
```

## Technologies used
- **C#**: To build the game logic and classes using OOP
- **.NET 10**: Framework used to develop the application
- **Spectre.Console**: To create a polished and interactive console interface

## What I learned
- The basics of Object-Oriented Programming (OOP) in C#
- How to build and structure an application in C#
- How to use the Spectre.Console package to enhance the command-line user experience
